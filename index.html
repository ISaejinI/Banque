Mini banque

Fonctionnalités :

  • ✅ Une base clients
  • ✅ Une base de comptes bancaires
  • ✅ Possibilité de créer un nouveau client
  • Possibilité de créer un nouveau compte bancaire pour un client
  • Possibilité de supprimer un compte bancaire
  • Possibilité de déposer de l’argent sur le compte d’un client
  • Possibilité de retirer de l’argent du compte d’un client
  • Possibilité de transférer de l’argent entre deux comptes
  • Possibilité d’afficher le solde d’un compte pour un client donné
  • Possibilité d’afficher l’historique des transactions pour un compte donné
  • Possibilité d’afficher l’argent total détenu par un client (tous comptes confondus)
  • Possibilité d’afficher l’argent total détenu par la banque (tous clients confondus)

Logique métier :

  • Chaque client peut avoir plusieurs comptes bancaires
  • Chaque compte bancaire appartient à un seul client
  • On ne peut supprimer un compte que s’il n’y a plus d’argent dessus
  • Chaque transaction est enregistrée dans l’historique du compte (deposit, withdrawal, transfer) et est datée
  • Lors d’un transfert, deux transactions sont créées (une pour le compte émetteur et une pour le compte récepteur)
  • Pas de découvert autorisé

Infos complémentaires :

  • Tout se fait dans la console (pas d’interface graphique)
  • Quand on dit 'afficher', c’est via console.log()
  • Privilégier une approche fonctionnelle (pas de POO)
  • Gérer les erreurs (ex : compte inexistant, solde insuffisant, etc.)
  • TOUT vérifier ! (Client/compte existant, montant positif, etc.)
  • Pour générer un identifiant unique, utiliser crypto.randomUUID()
  • Penser à factoriser le code au maximum

Bonus :

  • Possibilité d’appliquer des frais de tenue de compte mensuels (ex : 2€ par mois) => nouveau type de transaction fee
