Mini banque

Fonctionnalités :

  • ✅ Une base clients : datas.clients
  • ✅ Une base de comptes bancaires : datas.accounts
  • ✅ Possibilité de créer un nouveau client : createClient(prénom, nom de famille)
  • ✅ Possibilité de créer un nouveau compte bancaire pour un client : createAccount(id du client, nom du compte, montant du dépot d'ouverture)
  • ✅ Possibilité de supprimer un compte bancaire : deleteAccount(id du client, nom du compte)
  • ✅ Possibilité de déposer de l’argent sur le compte d’un client : deposit(id du client, nom du compte, montant du dépot)
  • ✅ Possibilité de retirer de l’argent du compte d’un client : withdrawal(id du client, nom du compte, montant du retrait)
  • ✅ Possibilité de transférer de l’argent entre deux comptes : transfert(id du client émetteur, nom du compte émetteur, id du client récepteur, nom du compte récepteur, montant du transfert)
  • ✅ Possibilité d’afficher le solde d’un compte pour un client donné : displayAccountBalance(id du client, nom du compte)
  • ✅ Possibilité d’afficher l’historique des transactions pour un compte donné : displayTransactions(id du client, nom du compte)
  • ✅ Possibilité d’afficher l’argent total détenu par un client (tous comptes confondus) : displayClientBalance(id du client)
  • ✅ Possibilité d’afficher l’argent total détenu par la banque (tous clients confondus) : displayBankBalance()

Logique métier :

  • ✅ Chaque client peut avoir plusieurs comptes bancaires
  • ✅ Chaque compte bancaire appartient à un seul client
  • ✅ On ne peut supprimer un compte que s’il n’y a plus d’argent dessus
  • ✅ Chaque transaction est enregistrée dans l’historique du compte (deposit, withdrawal, transfer) et est datée
  • ✅ Lors d’un transfert, deux transactions sont créées (une pour le compte émetteur et une pour le compte récepteur)
  • ✅ Pas de découvert autorisé

Infos complémentaires :

  • ✅ Tout se fait dans la console (pas d’interface graphique)
  • ✅ Quand on dit 'afficher', c’est via console.log()
  • ✅ Privilégier une approche fonctionnelle (pas de POO)
  • ✅ Gérer les erreurs (ex : compte inexistant, solde insuffisant, etc.)
  • ✅ TOUT vérifier ! (Client/compte existant, montant positif, etc.)
  • ✅ Pour générer un identifiant unique, utiliser crypto.randomUUID()
  • ✅ Penser à factoriser le code au maximum
